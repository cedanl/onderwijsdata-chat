# Wat kun je ermee

| Mogelijkheid | Wat je doet | Een voorbeeld |
|---|---|---|
| **Vragen in gewone taal** | Typ je vraag; de assistent kiest zelf de data. | "Hoeveel studenten zaten er in 2022 in het mbo?" |
| **Grafieken** | Vraag om een figuur; de assistent maakt een interactieve grafiek. | "Toon het aantal gediplomeerden in het mbo per jaar als grafiek." |
| **Kaarten** | Vraag naar een regionale vergelijking; de assistent kan een kaart maken. | "Vergelijk mbo-diplomering tussen regio's." |
| **Meerdere bronnen in één gesprek** | CBS, RIO, DUO en andere bronnen in één gesprek. | Zie [Databronnen begrijpen](databronnen.md). |
| **Dashboards** | Open de pagina Dashboards, waar de omgeving ze aanzet. Dat zijn drie vaste dashboards (Mijn instelling, Arbeidsmarkt, Landelijk), en waar de Studiekeuzedatabase aan staat vier, met Opleidingen. | Zie [Dashboards](../dashboards.md). |
| **Rapport** | Laat een analyse vastleggen in een rapport en download het als HTML, Markdown of Word, of sla het op als PDF. | Zie [Privacy in gewone taal](privacy.md) voor wat er bewaard wordt. |
| **Code en data erbij** | Zet in Instellingen **Geavanceerd** aan voor de Python-code per stap, de technische key, CSV-downloads en een modelkiezer. | Zie [Aan de slag als gebruiker](aan-de-slag.md). |
| **Herhalen en delen** | Exporteer een gesprek als Markdown, download "Bewijs (JSON)" bij een antwoord, of laat de analyse draaien met de code. | Zie [Een antwoord lezen](betrouwbaarheid.md). |

De technische beschrijving van de tools staat onder [Tools](../tools.md).

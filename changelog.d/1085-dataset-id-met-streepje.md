### De melding "Dataset … bestaat niet" noemt het hele ID, ook met een streepje (#1085)
- De controle op dataset-ID's stopte bij een streepje: bij "Zie ook DUO-bestand p09mbo-fantasie" meldde ze "Dataset
  p09mbo bestaat niet", een ander ID dan in de tekst stond. Ze noemt nu het ID zoals het er staat. Een bestaand ID met
  een woord erachter ("p01hoinges-bestand") blijft het bestaande ID, en leestekens erachter ("p01hoinges,") geven nog
  steeds geen melding.

### Chat: een codeverzoek toont de code van de juiste stap (#969)
- Heeft de laatste datastap geen code (collegegeld, een Inspectie-oordeel, mbo-indicatoren, accreditatie, een instelling
  uit RIO), dan zegt een vaste zin onder het antwoord dat er voor die stap geen code is. Eerder kwam daar de code van
  een eerdere stap, alsof die bij het antwoord hoorde. In een heropend gesprek zonder nieuwe datastap verwijst de zin
  naar "Bekijk code" bij het eerdere antwoord. Het codeblok noemt de stap waar de code bij hoort.
- Een vraag als "Wat is de CROHO code van …", "brin code", "de code van de Universiteit Utrecht", "ISCED code 0613" of
  "Python-cursussen" krijgt geen codeblok meer: alleen een verzoek om programmacode telt.
- Getallen in het codeblok krijgen geen citatie meer.
- Een UWV- of ROA-stap zonder selectie erna heeft nu ook code onder "Bekijk code".
